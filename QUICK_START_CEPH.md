# Quick Start: Ceph RGW Setup

This guide will help you quickly get started with Ceph RGW for S3-compatible storage in the metrics-utility project.

## Prerequisites

- Docker or Podman installed
- uv package manager (install with: `pip install uv`)
- PostgreSQL client tools (for verification)

## 1. Start Ceph RGW and PostgreSQL

```bash
cd tools/docker
docker compose up -d ceph-rgw ceph-rgw-setup postgres postgres-wait
```

Wait for all containers to be ready (about 10-30 seconds).

## 2. Verify the Setup

```bash
# From project root
./verify-ceph.sh
```

## 3. Set Environment Variables (Optional)

If you need to run commands outside of Docker:

```bash
export METRICS_UTILITY_BUCKET_ACCESS_KEY=myuseraccesskey
export METRICS_UTILITY_BUCKET_SECRET_KEY=myusersecretkey
export METRICS_UTILITY_BUCKET_ENDPOINT=http://localhost:9000
export METRICS_UTILITY_BUCKET_NAME=metricsutilitys3
export METRICS_UTILITY_BUCKET_REGION=us-east-1
```

## 4. Run Tests

```bash
# Run S3 storage tests
uv run pytest -s -v metrics_utility/test/library/test_storage_s3.py

# Run S3 gather tests
uv run pytest -s -v metrics_utility/test/gather/test_s3_gather.py

# Run all tests
uv run pytest -s -v
```

## 5. Use S3 Storage in Your Workflows

```bash
# Example: Gather data and ship to S3
export METRICS_UTILITY_REPORT_TYPE="CCSPv2"
export METRICS_UTILITY_SHIP_PATH="$$"
export METRICS_UTILITY_SHIP_TARGET="s3"

./run-s3-gather-build
```

## Common Commands

### View Logs

```bash
# Ceph RGW logs
docker logs ceph-rgw

# Setup logs
docker logs ceph-rgw-setup
```

### Stop Services

```bash
cd tools/docker
docker compose down
```

### Restart Services

```bash
cd tools/docker
docker compose restart ceph-rgw
```

### Get Current Credentials

```bash
./tools/docker/get-ceph-credentials.sh
```

### Access Ceph Admin

```bash
# Enter container
docker exec -it ceph-rgw bash

# List buckets
radosgw-admin bucket list

# Get user info
radosgw-admin user info --uid=demo-user

# Create new user
radosgw-admin user create \
  --uid=testuser \
  --display-name="Test User" \
  --access-key=testaccesskey \
  --secret-key=testsecretkey
```

## Troubleshooting

### Container won't start

```bash
# Check logs
docker logs ceph-rgw

# Check for port conflicts
lsof -i :9000

# Recreate container
cd tools/docker
docker compose down
docker compose up -d
```

### Bucket not found

```bash
# Check setup logs
docker logs ceph-rgw-setup

# Manually create bucket
docker exec -it ceph-rgw bash
aws s3 mb s3://metricsutilitys3 --endpoint-url http://localhost:7480
```

### Connection timeout

```bash
# Check if RGW is responding
curl -v http://localhost:9000

# Check container status
docker ps | grep ceph-rgw

# Check container health
docker inspect ceph-rgw
```

## What Changed from Garage?

**Container Service Name:**
- Before: `garage`
- After: `ceph-rgw`

**Internal Endpoint:**
- Before: `http://garage:3902`
- After: `http://ceph-rgw:7480`

**External Endpoint:**
- Before: `http://localhost:9000`
- After: `http://localhost:9000` (unchanged)

**Credentials:**
- Before: Generated by Garage (GK-prefixed keys)
- After: Configured via environment variables (customizable)

**Admin Interface:**
- Before: Garage Admin HTTP API
- After: `radosgw-admin` CLI

**Application Code:**
- No changes required! (S3 API is the same)
